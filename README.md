# Task 18 – Region Performance Analysis

## Dataset
Superstore Sales Dataset

## Objective
To compare sales and profit across different regions and identify the best-performing region.

## Tools Used
- Google Sheets

## Work Performed
- Created a region summary.
- Calculated total sales for East, West, Central and South.
- Calculated total profit for each region.
- Ranked regions based on total sales.
- Created a horizontal bar chart to compare sales and profit.
- Added key findings based on the analysis.

## Key Findings
- West recorded the highest sales and profit.
- East ranked second in sales.
- Central recorded the lowest profit.
- South had the lowest sales.

## Deliverables
- Region Summary
- Sales and Profit Analysis
- Sales Ranking
- Horizontal Bar Chart
- Key Findings
